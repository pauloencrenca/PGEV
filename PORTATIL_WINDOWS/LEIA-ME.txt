SISTEMA DE FORMULAS - VERSAO PORTATIL WINDOWS

1. Na maquina onde voce ja tem Maven e JDK 25, abra a pasta do projeto.
2. Clique duas vezes em CRIAR_PORTATIL.bat (precisa de internet na primeira preparacao).
3. Aguarde a mensagem SUCESSO. Sera criada a pasta PORTATIL_WINDOWS.
4. Copie a pasta PORTATIL_WINDOWS INTEIRA para outro computador Windows 64 bits.
5. Nesse computador, abra PORTATIL_WINDOWS e clique duas vezes em INICIAR.bat.
6. Acesse http://localhost:8080 caso o navegador nao abra automaticamente.

O Java e as bibliotecas estarao dentro da pasta PORTATIL_WINDOWS.
Nao sera necessario instalar Java nem Maven na maquina de destino.
O banco formulas.db sera criado dentro da pasta PORTATIL_WINDOWS.
Nao remova arquivos da pasta. Mantenha a janela preta aberta durante o uso.
Se o Windows bloquear arquivos baixados, consulte o responsavel pelo computador.
Em computadores de escola, restricoes de execucao podem impedir a abertura.
